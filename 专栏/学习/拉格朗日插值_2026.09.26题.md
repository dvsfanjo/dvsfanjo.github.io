## 拉格朗日插值



给定 $n$ 个点可以确定一个确定的最高次为 $n-1$ 次的多项式函数，而给定 $n$ 个点，求 $n$ 个点确定的函数在一个点上具体的值 $f(t)$ 就是拉格朗日插值做的事。



设给定的 $n$ 个点为 $(x_i,y_i)$ 则有：



$$f(t)=\sum_{i=1}^{n}(y_i\prod_{j\neq i}\frac{t-x_j}{x_i-x_j})$$



结论容易证明，只需要写下来就可以发现可以消元，保证一定经过给定的 $n$ 个点。



若 $(x_i,y_i)$ 有特殊性质可以优化上述式子，则时间复杂度可能更优，否则正常情况下做 $O(n^2)$ 次运算，若在模意义下还有逆元的复杂度。



```cpp

int lagrange(vector <pair <int, int>> poi, int k) {

	int ans = 0, n = poi.size();

	for (int i = 0; i < n; i++) {

		int tmp = poi[i].se;

		for (int j = 0; j < n; j++) {

			if (i == j) continue;

			tmp = tmp * (k - poi[j].fi + p) % p;

			tmp = tmp * ksm(poi[i].fi - poi[j].fi + p, p - 2) % p;

		}

		(ans += tmp) %= p;

	}

	return ans;

}

```



然后就是在 $x_i$ 连续时，拉格朗日插值是可以优化至 $O(n)$ 的（不算逆元。



```cpp

int lagrange(vector <pair <int, int>> poi, int k) {

	int ans = 0, n = poi.size();

	vector <int> pre(n + 2, 0), suc(n + 2, 0);

	pre[0] = suc[n + 1] = 1;

	for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] * (k - i + p) % p;

	for (int i = n; i >= 1; i--) suc[i] = suc[i + 1] * (k - i + p) % p;

	for (int i = 1; i <= n; i++) {

		int tmp = poi[i - 1].se;

		tmp = tmp * pre[i - 1] % p * suc[i + 1] % p;

		tmp = tmp * ksm(fac[i - 1] * fac[n - i] % p, p - 2) % p;

		if ((n - i) & 1) tmp = tmp * (p - 1) % p;

		(ans += tmp) %= p;

	}

	return ans;

}

```

## 模考 T3



给定 $n$ , $m$ , $k$ 求：



$$\sum_{i=m}^n \binom im \lfloor\frac im\rfloor \mod 998244353$$



$n\le10^9$ $m,k\le10^3$



显然首先可以想到按照 $\lfloor\frac im\rfloor$ 分块计算，为了方便，设 $q$ 是小于等于 $n$ 的最大的 $m$ 的倍数，而区间 $[q,n]$ 上的答案直接计算即可。



整块计算，即是：



$$\sum_{t=1}^{\frac qm -1}\sum_{i=tm}^{(t+1)m-1}\binom imt^k$$



将组合数变一下形式得到：



$$\sum_{i=l}^{r}\binom im=\binom{r+1}{m+1}-\binom l{m+1}$$



故原式为：



$$F(\frac qm - 1)=\sum_{t=1}^{\frac qm-1}[\binom{(t+1)m}{m+1}-\binom{tm}{m+1}] t^k$$



因为 $\binom {xm}{m+1}$ 是关于 $x$ 的 $m+1$ 次多项式函数，则它的差分 $\binom{xm}{m+1}-\binom{(x-1)m}{m+1}$ 是关于 $x$ 的 $m$ 次多项式函数。



算上 $t^k$ 则 $f(t)=[\binom{xm}{m+1}-\binom{(x-1)m}{m+1}]t^k$ 是 $m+k$ 次多项式函数，而要求的 $F(x)=\sum_{t=1}^xf(x)$ 是 $f(x)$ 的前缀和，综上 $F(x)$ 是关于 $x$ 的 $m+k+1$ 次多项式函数，只要预处理前 $m+k+2$ 个 $F(x)$ 即可用拉格朗日插值法求出 $F(\frac qm-1)$ 。

```cpp

#include <bits/stdc++.h>

#define int long long

#define fi first

#define se second

using namespace std;

const int maxn = 3e6 + 5, p = 998244353;

int n, m, k, q, fac[maxn], inv[maxn];

int ksm(int a, int b) {

	int res = 1; a %= p;

	while (b) {

		if (b & 1) res = res * a % p;

		a = a * a % p, b >>= 1;

	}

	return res;

}

int lagrange(vector <pair <int, int>> poi, int k) {

	int ans = 0, n = poi.size();

	vector <int> pre(n + 2, 0), suc(n + 2, 0);

	pre[0] = suc[n + 1] = 1;

	for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] * (k - i + p) % p;

	for (int i = n; i >= 1; i--) suc[i] = suc[i + 1] * (k - i + p) % p;

	for (int i = 1; i <= n; i++) {

		int tmp = poi[i - 1].se;

		tmp = tmp * pre[i - 1] % p * suc[i + 1] % p;

		tmp = tmp * ksm(fac[i - 1] * fac[n - i] % p, p - 2) % p;

		if ((n - i) & 1) tmp = tmp * (p - 1) % p;

		(ans += tmp) %= p;

	}

	return ans;

}

int calc() {

	auto C = [&](int x, int y)->int{

		if (x < y || y < 0) return 0;

		int ret = inv[y];

		for (int i = x - y + 1; i <= x; i++) {

			ret = ret * i % p;

		} 

		return ret;

	};

	return ksm(q, k) * (C(n + 1, m + 1) - C(q * m, m + 1) + p) % p;

}

void solve() {

	cin >> n >> m >> k;

	q = n / m;

	vector <pair <int, int>> poi;

	auto C = [&](int x, int y)->int{

		if (x < y || y < 0) return 0;

		return fac[x] * inv[y] % p * inv[x - y] % p;

	};

	for (int t = 1, F = 0; t <= m + k + 2; t++) {

		int ft = ksm(t, k) * (C(m * (t + 1), m + 1) - C(m * t, m + 1) + p) % p;

		(F += ft) %= p, poi.push_back(make_pair(t, F));

	}

	int sum1 = lagrange(poi, q - 1), sum2 = calc();

	cout << (sum1 + sum2) % p << '\n';

	return;

}

signed main() {

	ios::sync_with_stdio(0);

	cin.tie(0), cout.tie(0);

	fac[0] = inv[0] = 1;

	for (int i = 1; i <= 3000000; i++) {

		fac[i] = fac[i - 1] * i % p; 

		inv[i] = ksm(fac[i], p - 2);

	}

	int T; cin >> T;

	while (T--) solve();

	return 0;

}
```
