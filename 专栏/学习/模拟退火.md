## 模拟退火



模拟退火是一种随机化算法，在方案数很大时寻找局部最优解，再以一定的概率“跳出去”，得到全局最优解。



更详细的说，我们有一个当前温度，并在目前最优解的基础上进行一些修改，如果修改后答案更优，就接受这个解，否则以一定概率接受这个解。



要使最后的答案趋于稳定，每次修改、每次接受新解的概率应随温度变小而变小。



同时，为了更有效地找到优解，我们让一开始温度高的时间长一点，后面温度低的时间短一点。



## 算法流程



给定一开始的温度 $T_0$ （一个较大的正数），降温系数 $\Delta$ （一个接近 $1$ 的数）和结束温度 $T$ （一个接近 $0$ 的数），记一个随机数为 $r$ 。



1. 如果当前温度 $T_{now}<T$ ，结束程序。

2. 对答案进行随机修改，这里的修改应与 $T_{now}$ 的大小相关，如以 $r\cdot T_{now}$ 为增量（ $r$ 可正可负）。

3. 记答案为增量为 $\Delta ans$  ，如果结果更优，接受答案，否则以 $e^{-\frac{\Delta ans}{T_{now}}}$ 的概率接受答案。

4. 使 $T_{now} \to T_{now}\times\Delta$ 并回到第一步。



## 模板题



[P1337 [JSOI2004] 平衡点 / 吊打XXX](https://www.luogu.com.cn/problem/P1337)



如图，有 $n$ 个重物，每个重物系在一条足够长的绳子上。



每条绳子自上而下穿过桌面上的洞，然后系在一起。图中 $x$ 处就是公共的绳结。假设绳子是完全弹性的（即不会造成能量损失），桌子足够高（重物不会垂到地上），且忽略所有的摩擦，求绳结 $x$ 最终平衡于何处。



![](https://cdn.luogu.com.cn/upload/image_hosting/u20jvui9.png)



计算解时可能需要一些物理知识。



假设洞在 $(x,y)$ 处，那么稳定程度为 $\sum_{i=1}^{n} w_i \sqrt {(x-x_i)^2+(y-y_i)^2}$ 。



代码：



```cpp

#include <bits/stdc++.h>

using namespace std;

using ll = long long;

const int maxn = 1005;

ll n; double x[maxn], y[maxn], w[maxn];

double energy(double X, double Y) {

	double res = 0;

	for (int i = 1; i <= n; i++) {

		double dx = x[i] - X;

		double dy = y[i] - Y;

		res += sqrt(dx * dx + dy * dy) * w[i];

	}

	return res;

}

double ansx, ansy, answ;

inline double rng() {

	return rand() * 2 - RAND_MAX;

}

void SA() {

	double T = 3000, delta = 0.996;

	while (T > 1e-15) {

		double newx = ansx + rng() * T;

		double newy = ansy + rng() * T;

		double neww = energy(newx, newy);

		if (neww < answ) {

			ansx = newx;

			ansy = newy;

			answ = neww;

		} else if (exp(-(neww - answ) / T) * RAND_MAX > rand()) {

			ansx = newx;

			ansy = newy;

		}

		T *= delta;

	}

	return;

}

int main() {

	ios::sync_with_stdio(0);

	cin.tie(0); cout.tie(0);

	srand(19491001);

	cin >> n;

	for (int i = 1; i <= n; i++) {

		cin >> x[i] >> y[i] >> w[i];

		ansx += x[i];

		ansy += y[i];

	}

	ansx /= n;

	ansy /= n;

	answ = energy(ansx, ansy);

	SA(); SA(); SA(); SA();

	cout << fixed << setprecision(3) << ansx << ' ' << ansy << '\n';

	return 0;

}

```



## 一些问题



答案不是最优时，可以这样：



调大 $\Delta$ ，适当调整 $T_0$ 和 $T$ 。



多跑几次模拟退火，可以用上 ```clock()``` 函数限制次数。



分块，每个块内模拟退火。
