珂朵莉树讲义

2025-07-29 By dvsfanjo

珂朵莉树简介

珂朵莉树是珂朵莉发明的一种暴力数据结构，常用于解决区间颜色段覆盖问题，在随机数据下有不俗的表现，与线段树 O(nlog⁡n)O(n \log n)O(nlogn) 的时间复杂度相比，随机数据下珂朵莉树 O(nlog⁡log⁡n)O(n \log \log n)O(nloglogn) 的时间复杂度更优，同时，珂朵莉树还可以解决许多线段树解决不了的问题。

图解珂朵莉树

珂朵莉树本质是比较暴力的。

珂朵莉树将每个颜色段以 (l,r,x)(l,r,x)(l,r,x) 的方式存储，意思是区间 [l,r][l,r][l,r] 只有一种颜色 xxx 。

每次区间颜色段覆盖将 [l,r][l,r][l,r] 都染成 xxx 时，我们将 lll 和 rrr 所在的颜色段分裂开，再将夹在 lll 所在颜色段到 rrr 所在颜色段间的所有颜色段删除，插入颜色段 (l,r,x)(l,r,x)(l,r,x) 。

这就是珂朵莉树实现颜色段覆盖的原理。

其他操作

值得注意的是，在随机数据下，这样的时间复杂度十分低（原因下文再讲），期望颜色段只有 O(log⁡n)O(\log n)O(logn) 个。

删除中间所有颜色段的过程相当于将其遍历了一遍，所以各种奇奇怪怪的操作只要是与颜色段个数线性相关的，期望时间复杂度和区间推平操作一样都是 O(log⁡log⁡n)O(\log \log n)O(loglogn) 的（因为使用 set 维护颜色段多了一个 log⁡\loglog ），举几个例子。

  1. 将区间倒序，只需把所有颜色段删除后倒叙，修改其 (l,r)(l,r)(l,r) 后插入，与颜色段个数线性相关。
  2. 求区间贡献，其中 xxx 的贡献是 val(x)val(x)val(x) ，那么每个颜色段贡献为 (r−l+1)val(x)(r-l+1)val(x)(r−l+1)val(x) 。比如求区间和，或是 kkk 次方和，只需遍历每个颜色段加上贡献 (r−l+1)xk(r-l+1)x^k(r−l+1)xk 使用快速幂，时间复杂度 O(log⁡log⁡nlog⁡k)O(\log\log n \log k)O(loglognlogk) 。
  3. 区间交换，区间复制…

理论

还是将一下理论吧，但是也是感性证明不需要严谨过程，讲讲为什么颜色段是 log⁡n\log nlogn 的。

对于每次 splitsplitsplit 操作会增加一个颜色段；对于每次 assignassignassign 会最多增加 O(1)O(1)O(1) 个颜色段，删除最多 (n)(n)(n) 个颜色段，但事实上经过研究分析只会有 O(log⁡n)O(\log n)O(logn) 个颜色段，珂朵莉树时间复杂度保证就在推平操作。

假设每次操作是随机的，那么 lll 和 rrr 均匀分布，一个点 jjj 成为端点的概率 pjp_jpj​ 满足：

pj≈((j−1)2+(n−j)2n2)m p_j \approx \left( \frac{(j-1)^2 + (n-j)^2}{n^2} \right)^m pj​≈(n2(j−1)2+(n−j)2​)m

对所有点求和：

1n∑j=1npj=O(1m) \frac{1}{n} \sum_{j=1}^n p_j = O\left(\frac{1}{m}\right) n1​j=1∑n​pj​=O(m1​)

表示平均一个端点存活概率随操作次数增加而快速下降。

所以总端点数约为 O(n+m)O(n + m)O(n+m)，但由于随机覆盖，大部分会被合并掉。

仅少数端点幸存，根据积分估计：

E[t]=O(nm+log⁡m) E[t] = O\left(\frac{n}{m} + \log m\right) E[t]=O(mn​+logm)

当 m=nm = nm=n 时，有：

E[t]=O(log⁡n) E[t] = O(\log n) E[t]=O(logn)

ODT 的每次操作时间取决于区间数 ttt，平均操作时间为：

O(log⁡t)≈O(log⁡log⁡n) O(\log t) \approx O(\log \log n) O(logt)≈O(loglogn)

所以总体复杂度为均摊 O(nlog⁡log⁡n)O(n \log \log n)O(nloglogn)。

感性理解吧，或者当结论记就好了。

怎么卡掉珂朵莉树

上文提到过，珂朵莉树复杂度正确的核心是区间推平操作，那么我们只要使初始颜色段尽量多，没有推平，每次询问 [1,n][1,n][1,n] 就可以让时间复杂度退化至 O(n2log⁡n)O(n^2\log n)O(n2logn) 。

分块套珂朵莉树

结合一下分块思想，把序列分为 n\sqrt nn​ 个块，每个块内都是一个珂朵莉树，每次推平时，块外暴力推平，整块打一个标记，每次询问的复杂度为 O(log⁡log⁡n+log⁡n)O(\log \log n +\log \sqrt n)O(loglogn+logn​) ，最坏情况下总时间复杂度为 O(mnlog⁡n)O(m \sqrt n \log n)O(mn​logn) 。
