P2757 [国家集训队] 等差子序列

:::info[题意]
给定一个 $1$ ~ $n$ 的排列，判断是否存在一个等差子序列
:::
:::success[思路+代码]
等差子序列长度最小为 3 故我们只用判断有没有先后出现 $a-d$ 、 $a$ 和 $a+d$ 即可。

从左到右扫描线，对于 $a$ 如果先前出现了 $a-d$ 却没有出现 $a+d$ ，那么一定会有一个等差子序列。

换而言之，问题转化为了值域上的动态判断回文。

我们只用正、反分别维护哈希，就可以判断回文，又因为是动态的，我们用线段树维护哈希即可。

:::

使用字符串哈希+二分可以求 border 和最长回文半径，当然这是 $O(n\log n)$ 的远劣与 $O(n)$ 的 KMP 和 manacher 。

KMP

KMP 的核心在于计算每一个前缀最长 border 的方法（这里 border 是指子串 $S[1…i]$ 中同时是真前缀和真后缀的子串长度）。

用 $nxt(i)$ 表示前缀 $S[1…i]$ 的 border 长度，如果已知 $nxt(1…i-1)$ 如何求 $nxt(i)$ 呢。

  1. 如果 $s[nxt(i-1)+1]=s[i]$ 即 $nxt(i-1)$ 向后扩展一个下标后是 $nxt(i)$ ，可以得到 $nxt(i)=nxt(i-1)+1$ 。
  2. 不能向后扩展，我们只能尝试更小的 border 进行匹配，即 $nxt(nxt(i-1))$ ，若依旧不行就尝试 $nxt(nxt(nxt(i-1)))$ 直到成功。

例题

P4391 [BalticOI 2009] Radio Transmission 无线传输

:::info[题意]
给你一个字符串 $s_1$，它是由某个字符串 $s_2$ 不断自我连接形成的（保证至少重复 $2$ 次）。但是字符串 $s_2$ 是不确定的，现在只想知道它的最短长度是多少。
:::

:::success[思路+代码]
假设最短长度为 $x$ ，那么 $nxt(1…x)$ 都为 $0$ ， $nxt(x+1)=1$ ， $nxt(x+2)=2$ 等等。那么 $x = n - nxt(n)$ 。

:::

UVA1328 Period

:::info[题意]
求字符串每一个前缀是否是周期串，若是，输出前缀长度和循环节数量。
:::
:::success[思路+代码]
border 有一个性质：若 border 长度 $k$ 大于字符串的一半，且 $n$ 能被 $n-k$ 整除，那么字符串就是周期串，且 $n-k$ 就是字符串最长循环节的长度。

:::

exKMP Z函数

exKMP 要求的东西和 KMP 有点像（当然也是有差别的），我们定义 $z(i)$ 为 $s$ 与以 $i$ 开头的 $s$ 的后缀的最长公共前缀的长度，即 LCP 的长度（其实就是有不同限制条件的 border 啦）。

我们将维护一个右端点最大的匹配区间 $[l,r]$ 和 $z(1…i-1)$ 来求出 $z(i)$ ，我们分为以下几种情况：

  • $i\le r$ 时，有 $s[i-l,r-l]=s[i,r]$ 故 $z(i)\ge \min(z(i-l),r-i+1)$ ，若 $z(i-l)\le r-i+1$ 则 $z(i)=z(i-l)$ 否则令 $z(i)=r-i+1$ 再暴力扩展
  • $l\ge r$ 时，直接暴力扩展

最后用 $z(i)$ 更新 $[l,r]$ 即可。

用 KMP 同样的分析方法，可以得到时间复杂度为 $O(n)$ 。同样可以求 $t$ 与每一个 $s$ 的后缀的 LCP 长度（就是模板题啦）。

LCP 也是一种 border 所以可以做字符串匹配。

例题

P9576 「TAOI-2」Ciallo～(∠・ω< )⌒★

:::info[题意]
绫地宁宁大战秘密武器！

给定字符串 $s$ ，求有几种至少一个数不同的 $(l,r,l_1,r_1)$ 使得 $1\le l_1\le l\le r\le r_1\le n$ 且 $s(l..l_1)+s(r_1…r)=t$ ，如果 $s(l…r)$ 中 $r<l$ 则其为空串。

$s$ 长为 $n$ 且 $t$ 长为 $m$ 。
:::
:::success[思路+代码]
首先如果 $t$ 是 $s$ 的一个子串那就很容易统计了。

如果 $t$ 被分为了两段，那么我们要使 $LCS(s(l_1…r_1),t)+LCP(s(l_1…r_1))\ge m$ 。

令 $p_1(i)=LCS(s(i…n),t)$ ， $p_2(i)=LCP(s(1…i),t)$ 。这两个可以用 exKMP 求，只需要将字符串倒序正序算即可。

最后我们要统计 $(i,j)$ 的数量，要保证 $j\ge i + m$ 且 $p_1(i)+p_2(j)\ge m$ ，这就是二位数点，用树状数组算即可。

:::

CF432D Prefixes and Suffixes

完了口胡完发现只要 DP 就行了。
:::

Manacher

Manacher 算法是用来查找回文子串的。首先我们知道，回文串长度有奇有偶，因此我们一般会对字符串进行处理。

那么从其中提取原字符串的回文子串也很简单，语法题，不多赘述。

$r$ 从 $-1$ 已知不减地增长到 $n$ ，而 $r$ 又是决定 while 循环次数的，所以此时间复杂度为 $O(n)$ ，外层循环次数为 $O(n)$ ，所以总时间复杂度为线性。

例题

P4555 [国家集训队] 最长双回文串

:::info[题意]
求两个相邻回文串长度之和最大。
:::
:::success[思路+代码]
首先进行处理，将 baacaabbacabb 变成 #b#a#a#c#a#a#b#b#a#c#a#b#b# ，我们计算 $suc(i)$ 为以 $i$ 开头的最长回文子串长度和 $pre(i)$ 为以 $i$ 结尾的最长回文子串长度，最后枚举每一个 ‘#’ 的位置 $i$ 计算 $\max suc(i)+pre(i)$ 即可。

每次做完 Manacher 算出 $d(i)$ 时，我们将更新 $pre(i+d(i)-1)$ 和 $suc(i-d(i)+1)$ 的值，最后从头到尾处理每一个 ‘#’ 的 $suc(i)=\max(suc(i),suc(i-2)-2)$ ，从尾到头处理每一个 ‘#’ 的 $pre(i)=\max(pre(i),pre(i+2)-2)$ 即可（其实算是动态规划）。

:::

P4287 [SHOI2011] 双倍回文

:::info[题意]
求字符串中由两个相同的偶回文串拼起来的回文子串的最大长度。
:::
:::success[思路+代码]

看似很复杂，但事实上这样的回文串满足以下性质：

  • 这个子串是回文串
  • 长度为 $4$ 的倍数
  • 这个子串的前一半也是回文串

只要发现新区间超过 $[l,r]$ 时向后暴力检查即可。

复杂度为什么正确呢？在 if (i % 2) 中的循环次数总量显然和 k 的增量差不多，而 k 的增量是 $O(n)$ 的，所以总复杂度仍然是 $O(n)$ 。
:::

Trie 字典树

Trie 是一种树状结构（废话），每一个字符串都是树上从根开始的一条链，通过共用前缀维护多个字符串，比如 aabaa 和 aabacd 中的 aaba 在树上就是共用一条链。

同时还有一个叫 01Trie 的东西，用来做位运算相关的东西（就是把一个数的二进制形式当作字符串插入字典树），这东西还能当平衡树使，还能可持久化，但这就超出字符串的范围了，不多说。

例题

P4551 最长异或路径

:::info[题意]
给定一棵树，求异或和最大的路径的异或会。
:::
:::success[思路+代码]
一段路径的异或和连着异或两次会消失，令 $dis(u)$ 为 $1$ 到 $u$ 的异或和，那么点对 $(u,v)$ 之间的异或和为 $dis(u)\otimes dis(v)$ 。

在 01Trie 中插入每一个 $dis(i)$ ，枚举 $i$ 得到其最优答案。

:::

fail 树

对于 KMP 求出的 border 数组，将 $i$ 与 $border_i$ 连边，得到一个以 $0$ 为根节点的 border 树，即 fail 树。在 fail 树上，点 $u$ 的祖先都是它的 border 长度。

KMP 自动机

KMP 自动机是弱化版的 AC 自动机，相当于单串的 AC 自动机。先建一个 fail 树，设 $nxt_{i,j}$ 表示从 $i$ 开始沿着 fail 树向上跳得到的最大的位置 $k$ 使 $s_{k+1}=j$ 。

注意到此时我们可以把 KMP 求的过程表示为：对于 $i$ ，从 $fail_{i−1}$ 开始沿着 fail 树向上跳找到的最大的位置 $k$ 使 $s_{k+1}=s_i$ ，若不存在则为 $0$ 。这也可以让我们得到 $fail_i=nxt_{fail_{i−1,s_i}}$ 。
