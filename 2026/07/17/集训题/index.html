Day 1

A - Recovering BST

给定一个长为 $n$ 有序数列 $a$ 作为一个 BST 的中序遍历的节点点权，是否存在这样的 BST 使得两两相连的点权不互素。

$n\le 700,a_i\le10^9$

一个 BST 的中序遍历中，一棵子树一定是一段区间，很容易想到区间 DP 。一开始设计状态为 $f[l][r][u]$ 是区间 $[l,r]$ 以 $u$ 为根的子树是否存在，此时枚举区间和根复杂度达到 $O(n^3)$ ，此时还要判断根的左右子树是否存在根与 $u$ 相连，使用 bitset 优化可以达到 $O(\frac{n}{\omega})$ 的复杂度，但总复杂度不够优秀。

但是一个区间 $[l,r]$ 为子树，它的根的父亲一定是 $l-1$ 或 $r+1$ ，优化状态为 $f[l][r][0/1]$ 表示以 $[l,r]$ 为子树的区间的根的父亲是否可以为左/右一个节点，只需枚举区间和根，此时转移时间复杂度为 $O(n^3)$ 。

两两节点间互素关系先预处理出来，否则总时间复杂度还要加一个 log 。

B - Yet Another Array Counting Problem

多组询问，给定一个长为 $n$ 的序列 $a$ ，求一个长为 $n$ 值域为 $[1,m]$ 的序列 $b$ 满足其每一个区间最左边最大值的位置与对应 $a$ 的区间的最左最大值位置一致，求序列 $b$ 的数量对 $998244353$ 取模。

$\sum nm\le 10^6$

先考虑怎样的序列满足每个区间的最左最大值位置与 $a$ 一致。在 $a$ 的区间 $[l,r]$ 中找到最左最大值位置 $p$ 并以其为节点，处理 $[l,p-1]$ 和 $[p+1,r]$ 为左右儿子，形成一颗 BST 满足左子树一定比该节点小，右子树小于等于该节点，若像这样处理 $b$ 的 BST 与 $a$ 的 BST 一致，则 $b$ 的所有最左最大值位置与 $a$ 一致。

设状态 $f[u][k]$ 为节点 $u$ 小于等于 $k$ 的方案总数，对于空节点的值应该为 $1$ ，叶子节点的值为 $k$ ，容易得到转移方程：

$$f[u][k] = f[u][k-1]+f[L][k-1]\times f[R][k]$$

其中 $L$ 和 $R$ 表示左右节点，时间复杂度为 $O(nm)$ 。

C - Count Binary Strings

求二进制串 $s$ 满足一些条件，当 $a_{i,j}=1$ 时 $s[i…j]$ 数字相同；当 $a_{i,j}=2$ 时 $s[i…j]$ 有不同数字。求满足的 $s$ 的数量模 $998244353$ 。

$|s|\le1000$

将限制条件简化，我们设转移状态为 $f[i][j]$ 表示前 $i$ 个数中的最长相同后缀长度为 $j$ ，当 $a_{l,r}=1$ 时，说明 $r$ 对应的最长相同后缀长度至少为 $r-l+1$ ；当 $a_{l,r}=2$ 时，说明 $r$ 对应的最长相同后缀长度至多为 $r-l$ ，综上，我们可以确定长度的上下界。

那么对于 $j=1$ 时，有 $f[i][j] = \sum_{x\in[1,i)} f[i-1][x]$ ，否则有 $f[i][j] = f[i - 1][j-1]$ ，随后将长度上下界以外的状态设为 $0$ 即可，因为第一个数可以是 $0$ 或 $1$ ，则 $f[1][1]=2$ ，最后答案为 $\sum f[n][j]$ 。

D - Binary String Wowee

给定二进制串 $s$ ，一次操作是将任意一个 $s_i=0$ 的 $[1,i]$ 反转，将进行 $k$ 次操作，问不同的操作方式有多少。

从后往前考虑没有后效性，当在 $i$ 进行操作时，若 $s_i=0$ 则在 $(i,n]$ 上有偶数次操作，否则有奇数次操作。设 $f[i][j]$ 为在 $[i,n]$ 上做了 $j$ 次操作的方案数。设在 $i$ 做了 $x$ 次操作，那么保持在 $(i,n]$ 上的 $j$ 次操作相对位置一致，在偶/奇数位置插入 $x$ 个操作，细说：

若 $s_i=0$ 则 $f[i][j]=\sum f[i+1][j-x]\times C_{\lceil j\rceil}^{x}$

若 $s_i=1$ 则 $f[i][j]=\sum f[i+1][j-x]\times C_{\lfloor j\rfloor}^{x}$

E - Jongmah

给你颜色在 $[1,m]$ 内的牌共 $n$ 个，可以取出 $(i-1,i,i+1)$ 和 $(i,i,i)$ 问最多可以去多少个。一个 $(i-1,i,i+1)$ 最多出现两次，否则会变为 $(i,i,i)$ 处理，设 $f[i][a][b]$ 为前 $i$ 个有 $a$ 个 $(i-1,i,i+1)$ 和 $b$ 个 $(i,i+1,i+2)$ 。

$$f[i][b][c] = \max(f[i-1][a][b]+c+\lfloor\frac{cnt_i-a-b-c}{3}\rfloor)$$

答案显然为 $f[m][0][0]$ 。

F - Almost Triple Deletions

给定长为 $n$ 的数组 $a$ ，一次操作可以选相邻不同数删除，最后最多可以留下多少相同的数。

这样的区间可以被完全删除：长度为偶数且众数数量不超过区间长度的一半，证明略。我们预处理每一个区间是否可以被完全删除，然后定义 $f[i]$ 是前 $i$ 个数中可以留下多少个 $a_i$ ，通过前面与 $a_i$ 值相等的数进行转移即可，加一写特判，如：第一个这样的数要满足前面的东西都可以被删掉，最后的数要满足后面的数都可以被删掉。

G - Fuel Round Trip

数轴上从 $a_1$ 出发到 $a_n$ 再回到 $a_1$ ，经过一个单位长度耗一升油，有 $n$ 个加油站为 $a$ 数组，第 $i$ 个加油站可花费 $p_i$ 加 $f_i$ 升油，往返不得在同一个加油站加油，油箱上限为 $h$ 升，问最小花费为多少。

因为有后效性不好做，所以设计状态时要把往返状态都加进去，这里令 $F[i][a][b]$ 为从 $1$ 到 $i$ 有 $a$ 升油，回来有 $b$ 升，根据题意转移即可，注意边界条件。

H - Kaavi and Magic Spell

给定字符串 $S$ 和 $T$ 分别长为 $n$ 和 $m$ ，有一个空串 $A$ ，一次操作可以删除 $S$ 的第一个字符并添加至 $A$ 的首部或尾部，共 $n$ 次操作，使得 $T$ 是 $A$ 的前缀的方案数是多少。

设 $f[l][r]$ 为 $S$ 的前 $r-l+1$ 个字符组成 $T(l…r)$ 的方案数，边界条件是当 $T_i=S_1$ 时 $f[i][i]=2$ ，转移很显然，当 $S_{len}=T_l$ 时 $f[l][r]$ 由 $f[l+1][r]$ 得，当 $S_{len}=T_r$ 时 $f[l][r]$ 由 $f[l][r-1]$ 得。

Day 2

A 书架平衡

有 $n$ 个数对 $u_i$ 和 $d_i$ 以及一个整数 $k$ ，花费一个金币可以让任意一个数减一，问最少花费多少可以使：

  1. $u_i+d_i=h$ 其中 $h$ 是定值
  2. $|u_i-u_{i-1}|\le k$ 即相邻的 $u$ 之间差值不大于 $k$

乍看没什么思路，很多东西也没有特殊限制，不妨找一下，发现第二个条件有点难调，但是由于只能减数，于是可以确定每对数减多少，发现 $h$ 的合法性是单调的，于是我们使用二分答案得到最大的合法 $h$ ，答案即为 $\sum(u_i+d_i)-nh$ 。

如何检查是否可以使得差值不大于 $k$ 呢，因为 $u_i+d_i$ 整体要减为 $h$ ，因此可以推导出 $u_i$ 减后的上下界。设当前的上下界为 $[l,r]$ 随后将其扩展至 $[l-k,r+k]$ 与下一个 $u_i$ 的上下界去并，重复操作，若最后得到的上下界是空集则检查不通过。

综上检查 $O(n)$ 在二分的基础上时间复杂度为 $O(n\log n)$ 而 $n=2\times 10^5$ 可以通过。

B 宴会后厨

有 $n$ 道菜，每道菜所需时间为 $a_i$ 小时，一道菜至少要 $k$ 个厨师参与。有 $m$ 个厨师，每个人可以花费 $b_i$ 小时，同时无论如何只要厨师工作就一定会支付 $b_i$ 的工资。求最少浪费的工资，即要使厨师不工作但得到工资的时间最少，并输出这个最小值，详细来讲，设选的厨师的集合为 $S$ 则答案为 $\sum_{i\in S} b_i-\sum a_i$ ，不可能则输出 Impossible 。

先判断无解的情况，显然 $a_i<k$ 的情况是无解的。一道菜可以拆分为 $k$ 个不同人贡献的基础小时和 $a_i-k$ 人贡献的额外小时，显然一个厨师的基础小时最多为 $\min(n,b_j)$ 且厨师贡献的基础小时之和一定不小于每道菜的厨师种类之和即 $nk\le\sum\min(n,b_j)$ 。啪一下变成了 01 背包问题了，设 $f_{i,j}$ 为前 $i$ 个厨师总雇佣时间为 $j$ 的最大基础小时之和，做 01 背包加滚动数组即可，因为 $a_i$ 和 $b_i$ 和 $n$ 同阶，时间复杂度为 $O(n^3)$ 而 $n\le300$ 可以通过。

C 边防军阵

给定一个 $n$ 个节点的树和 $m$ 个点对 $(u_i,v_i)$ 。对于每个点对可以在这个点对之间的简单路径上的边打标记，或在除了点对之间的简单路径上的边打标记，求最后有标记的边数的最小值。

正难则反，我们求没有标记的边数的最大值 $M$ 则答案为 $n-1-M$ 。任意两条边只有被标记的的状态相同才能一起不被覆盖，状态相同的边集的大小的最大值即为 $M$ 。现在考虑如何标记/链修改状态，使用 XorHash 可以做到，只要做类似树上差分的东西就可以，将每一个边的哈希值向上合并，最后用一个 umap 统计即可。注意：出题人很闲会卡 mt19937_64 的哈希。

Day 3

A - 「KWOI R2」染色

将长度为 $n$ 的序列 $a$ 拆分为两个子序列使得这两个子序列的相邻两个数的差的绝对值的和最大。

显然可以列出 DP 状态 $f[i]$ 表示前 $i$ 个中的最大值，设 $s[i]=\sum_{x=2}^{x\le i}|a[i]-a[i-1]|$ 则有 $f[i] = \max(f[j] + |a[i] - a[j]| + s[i - 1] - s[j])$ 。

有绝对值不好做，但是有一个相关 trick ： $|a-b|=\max(a-b,b-a)$ 可以将式子转化为 $\max$ 套 $\max$ 化简变成 $f[i]= \max(\max(f[j] - a[j] - s[j]) + (s[i - 1] + a[i]),\ max(f[j] + a[j] - s[j]) + (s[i - 1] - a[i]))$

其中的 $\max(f[j]-a[j]-s[j])$ 和 $\max(f[j]+a[j]-s[j])$ 使用前缀最大值维护。

B - Discharging

将一个长为 $n$ 的序列分组，第 $i$ 个人等待的时间是当前组和前面的所有组中的最大值之和，求所有人等待时间最小值。

$f[i]$ 为前 $i$ 个中分完组的时间最大值
在 $[l,r]$ 中最大值为 $k$ 则 $a[r + 1] > k$ 否则 $[l,r+1]$ 更优。

使 $b[i] = \max(a[1..i])$ , 则列出 $f[i] = max(f[j] + (n-j) \times b[i])$ 。

设决策点为 $j$ 得：

在上凸包中试斜率为 $k$ 的直线，截距最大的即为所求
用单调栈维护上凸包，用一个指针在栈中寻找斜率最正确的 $j$ 即可。

C - Vasya and Array

一个长度为 $n$ 的数列，每个数为 $[1,k]$ 中的整数或 $-1$ 且 $-1$ 可以被更改为任意 $[1,k]$ 中的整数，求最后不存在连续 $len$ 个相同数字的操作方案数。

$n\le10^5,k\le100$

首先列出状态 $f[i][j]$ 表示第 $i$ 个位置放 $j$ 的合法方案数，设 $s[i] = \sum f[i][k]$ 。

先不考虑 $len$ 的限制：

  1. $a[i]=j$ 则可以接在所有 $i-1$ 后面
  2. $a[i]=-1$ 可以填 $[1,k]$ 任意数字
  3. 其他情况方案数为 $0$ 。

则 f[i][j] = (a[i] == -1 || a[i] == j) ? s[ - 1] : 0 。

然后减去填上 $j$ 后第一次形成连续 $len$ 个 $j$ 的非法方案数，在每一个位置都排除首次非法方案可以避免重复统计。前 $i-1$ 个都是合法的，只有可能是第 $i$ 个是第 $len$ 个 $j$ 。

此时非法方案为 $\sum_{c\neq j}f[i-len][c] = s[i-len] - f[i-len][j]$ 。同时要用前缀和判断 $[]i-len+1,i$ 中是否只有 $j$ 和 $-1$ 。

时间复杂度 $O(nk)$ 。

E - Patisserie ABC 3

有 $n$ 个蛋糕，第 $i$ 个蛋糕有属性 $(x_i,y_i,z_i)$ ，选取 $k$ 对蛋糕，一对蛋糕的美味值为 $\max(x_i+x_j,y_i+y_j,z_i+z_j)$ 求总美味值最大为多少。

首先发现一坨 $\max(x_i+x_j,y_i+y_j,z_i+z_j)$ 很难处理，于是想到让每一个蛋糕自主选择哪个值参与配对，那么选了哪些蛋糕就不重要了，重要的变为目前三种值存在的奇偶性，若是奇数，则当前蛋糕可以配对，最后在动态规划过程中求得的最大值即为所求，于是自然而然地列出状态：用 $f_{i,j,mask}$ 表示前 $i$ 个蛋糕中选了 $j$ 个蛋糕，目前三种状态的奇偶性为 $mask$ ，其中 $mask$ 是一个三位二进制数。

显然可以分情况，当前不选，当前选用 $x$ 或 $y$ 或 $z$ 值配对，即：

答案为 $f_{n,2k,0}$

时间复杂度 $O(nk)$ 不能通过。

设选 $i$ 个蛋糕最后的最大值为 $F(i)$ 并可以发现以下特征：

  1. 题目中要求在 $n$ 个蛋糕中选 $2k$ 个。
  2. 如果没有 $2k$ 个的限制会很容易求，只需要把 DP 的第二维去掉即可。
  3. 函数 $F(i)$ 有凸性，显然的，设 $F(x_0)$ 是最大值，则 $|i-x_0|$ 越大，答案 $F(i)$ 只会更劣。

综上，这道题完全符合使用 wqs 二分的性质！

二分斜率即可，但是斜率可能出现 $0.5$ 所以有乘除 $2$ 的处理，同时我们还要计算当前斜率下的蛋糕数，只需在成功转移时记录即可。

Day 4

A - 01 on Tree

给定 $n$ 个节点的树，每个节点权值为 $0$ 或 $1$ 求树上节点的拓扑序使得组成序列的逆序对数最小。

不考虑拓扑序的限制，则 00..0111..1 是最优的 ，于是想到，有 $v[i] = 0$ 则一旦父亲被选了则立即选它，我们可以将其与父亲节点合并。

fa[x] A1 A2 A3 x

其中 $A1$ $A2$ $A3$ 应是 $x$ 的兄弟子树，每个兄弟子树应该有一个权值，套路 Exchange Argument 考虑相邻两个块 $a, b$ ，逆序对数量 $cnt_a1 * cnt_b0 < cnt_b1 * cnt_a0$ 时，显然 $a$ 在 $b$ 前面，那么每个节点的权值为 $\frac{cnt1}{cnt0}$ 。

用 set 维护权值，每次取最小的一个与父亲节点合并，用并查集维护答案。

B - 皇后游戏

每个大臣有两个数 $a_i$ 和 $b_i$ 求一种排序顺序使得 $c_i = max(c_{i-1}, \sum_{j\le i} a_i) + b_i$ 最大，使用 Exchange Argument 来寻找贪心规则，若相邻的 $i < j$ 是优的，设 $i$ 前的 $a$ 之和为 $x$ ， $i$ 前的 $c$ 为 $y$ 则较大的 $c$ 值：

$$\max(\max(y, x + a_i) + b_i, x + a_i + a_j) + b_j$$

$$\max(y + b_i + b_j, x + a_i + b_i + b_j, x + a_i + a_j + b_j)$$
交换 $i$ $j$ 后为：

$$\max(y + b_i + b_j, x + a_j + b_i + b_j, x + a_i + a_j + b_i) $$

按照题意：

$$\max(x + a_i + b_i + b_j, x + a_i + a_j + b_j) \le \max(x + a_j + b_i + b_j, x + a_i + a_j + b_i)$$

消去 x 得：
$$a_i + b_j + \max(b_i, a_j) \le a_j + b_i + \max(b_j, a_i)$$
$$\max(a_j, b_i) - a_j - b_i \le \max(a_i, b_j) - a_i - b_j$$

因为 $\max(a, b) - a - b = -\min(a, b)$ 则：

$$-\min(a_j, b_i) \le -\min(a_i, b_j)$$

$$\min(a_i, b_j) \le \min(a_j, b_i) $$

小于等于不满足传递性，于是继续优化：

$\min(a_i, b_j) \le \min(a_j, b_i)$ 有以下三种可能：

  1. $a_i < b_i$ 且 $a_j < b_j$ ，此时要按 $a$ 升序排序
  2. $a_i = b_i$ 且 $a_j = b_j$ ，此时无限制
  3. $a_i > b_i$ 且 $a_j > b_j$ ，此时要按 $b$ 降序排序
    这样就满足传递性了。

有 $x+y+z$ 个人，每个人有 $a_i$ $b_i$ $c_i$ 个三种不同的钱，这三种分别要 $x$ $y$ $z$ 个，求最后最大总钱数

先简化问题，三种钱太麻烦了，我们将三元组 $(a_i,b_i,c_i)$ 变为二元组 $(a_i-c_i,b_i-c_i)$ ，即默认每个人都贡献第三种钱，然后选 $x$ 个人贡献 $a_i-c_i$ 个第一种和 $y$ 个人贡献 $b_i-c_i$ 个第二种。

分界点越左越好，二分这个分界点即可。

选取 $s$ 的长为 $L$ 的前后缀，求使前后缀循环同构的最大 $L$ 。

循环同构的前后缀使得字符串为 $ABSBA$ 的形式，设 $s_{1…n}$ 的 border 为 $A$ ，而 $s_{|A|+1,…,n-|A|}$ 的 border 为 $B$ ，答案为 $\max(|A|+|B|)$ 。

首先 $A$ 是好求的，用一次 KMP 就可以将所有 $A$ 求出。求 $B$ 时从中心扩展将所有 $B$ 求出，设 $[i+1,n-i]$ 的 border 长度为 $L$ 则 $[i,n-i+1]$ 的 border 长度不大于直接转移的 $L+2$ ，若不再是 border 则减小 $L$ 判断，总共最多只有 $L$ 次减少。
